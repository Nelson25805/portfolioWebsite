Project Overview

The IGDB Game Data Fetcher is a Python-based project designed to interact with the IGDB API to fetch detailed video game information. It allows users to search for games, view relevant data, and save results into an Excel sheet for offline use or further analysis.

Key Features

  • Game Search: Search the IGDB database for detailed information about games, including titles, genres, and release dates.
  • Excel Export: Save search results into an organized Excel sheet for easy access and sharing.
  • Customizable Queries: Tailor API calls to fetch specific types of game data.

Technical Details

  • Programming Language: Python for backend logic and API integration.
  • API: Uses the IGDB API for fetching game-related data.
  • Data Handling: Parsed JSON responses from the API and structured them into an Excel-friendly format using libraries like pandas and openpyxl.
  • Rate Limiting: Implemented efficient request management to adhere to IGDB’s API rate limits.

Challenges & Solutions

  • Rate Limits: Designed a queue system to manage API requests within IGDB’s constraints, avoiding errors and delays.
  • Data Formatting: Created a user-friendly Excel template to make saved data easy to read and use.
  • Image Handling: Integrated logic to fetch and save cover art for games when available, avoiding errors from missing fields.

Future Improvements

  • Enhance the GUI to make it more user-friendly and visually appealing.
  • Introduce additional data visualization options, such as charts or graphs within Excel outputs.
  • Implement search result caching to reduce redundant API calls.
